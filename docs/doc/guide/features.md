# 功能说明

## 构建索引

- 为大型音频目录（WAV、FLAC、MP3、OGG、OPUS、AAC、M4A、WMA、AIFF 等）建立本地指纹索引。
- 支持按目标加载内存（MB）分段建库。
- 支持增量构建：仅处理尚未入索引的新文件，默认使用索引原分段大小。
- 支持多线程并行与递归扫描。

## 检索与结果

- 通过短片段或长样本定位源文件与文件内偏移。
- 可按文件名合并结果，以最高置信度展示。
- 检索任务跨页面持续，返回检索页即可查看状态或结果。
- 从命中偏移开始播放完整源文件，跨页面持续播放。

## 收藏与导出

- 收藏与取消收藏，收藏页展示收藏时间。
- 在 Windows 资源管理器中定位源文件。
- 按样本时间线拼接导出匹配结果。

## 索引缓存

后端默认在内存中保留最近使用的索引分段（LRU，限 4 段），连续检索无需重复加载。内存紧张时可在「设置」中开启「检索后卸载索引」。
