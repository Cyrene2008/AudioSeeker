# 功能说明

## 构建索引

- 为大型音频目录建立本地指纹索引，支持 WAV、FLAC、MP3、OGG、OGA、OPUS、AAC、M4A、MP4、WMA、AIFF、AIF 等常见格式，可混合存放。
- 支持按目标加载内存（MB）分段建库：每段一个 `seg_XXX` 目录，加载与匹配按段进行。
- 支持多线程并行构建（默认 8 进程，上限 64）。
- 支持断点续建：重新开始时已完成的文件会被跳过。
- 支持增量构建：仅处理尚未入索引的新文件，默认使用索引原分段大小；旧索引无元数据时默认为 `0 MB`（单段）。

## 检索与结果

- 通过短片段或长样本定位源文件与文件内偏移。
- 支持样本起止时间裁剪与阈值调整（最小命中数、最低置信度）。
- 检索任务跨页面持续，返回检索页即可查看状态或结果；进度不可精确量化，使用不确定进度环。
- 支持按文件名合并结果，以最高置信度展示，并标注合并命中数量。

## 播放

- 从命中偏移开始播放完整源文件（不再是截断片段）。
- 播放器跨页面持续播放，可拖动进度、调节音量与倍速。

## 收藏与导出

- 收藏与取消收藏（再次点击实心星即取消），收藏页展示收藏时间。
- 在 Windows 资源管理器中定位源文件。
- 按样本时间线拼接匹配结果并导出为 WAV 文件；支持导出所选与导出全部。

## 索引缓存

后端默认在内存中保留最近使用的索引分段（LRU，最多 4 段），连续检索同一索引无需重复加载。内存紧张时可在「设置」中开启「检索后卸载索引」，每次检索结束后释放本次使用的分段。

## 检索历史

每次检索自动保存历史记录，可载入结果、再次导出，也可删除。

## 界面

- 中英文双语界面。
- 浅色 / 深色模式。
- 桃粉主题，基于 VueFluentWidgets Fluent Design 组件库。
