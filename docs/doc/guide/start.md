# 快速开始

## 安装

1. 从 [GitHub Releases](https://github.com/Cyrene2008/AudioSeeker/releases) 下载最新的 Windows 安装包。
2. 运行 `AudioSeeker_<版本>_x64-setup.exe`。
3. 首次启动时等待运行环境准备完成（下载 Python 运行时、安装依赖、准备 FFmpeg）。

## 第一次使用

1. 进入「构建索引」页面，选择包含音频文件（WAV、FLAC、MP3、OGG、AAC、M4A 等）的目录。
2. 输入索引名称，按需设置线程数与目标段加载内存（MB）。
3. 开始构建，等待任务完成。
4. 进入「开始检索」，选择索引与样本音频，开始匹配。
5. 在结果中播放、收藏或导出匹配内容。

## 数据目录

- 默认索引目录：软件安装目录下的 `index` 文件夹。
- 设置、收藏、历史与索引注册信息：当前用户的应用数据目录。
